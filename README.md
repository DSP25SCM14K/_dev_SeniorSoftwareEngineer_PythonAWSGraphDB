# Dev Kumar — Connected Systems

An interactive portfolio centered on production Python services, event-driven
AWS architecture, and graph-backed decision systems.

## Included

- Animated graph traversal and rotating Cypher, Gremlin, and event queries
- Responsive event-to-answer architecture
- All 15 work-experience bullets from the source résumé
- 16 project source links and demos only for the four supplied demos
- Research paper, notebook, certificate, GitHub, LeetCode, Scholar, and résumé
- Reduced-motion support and keyboard-accessible controls
- No LinkedIn and no footer
